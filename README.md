# VoidGram Offers

Seven modifications for Telegram — each folder holds the full source of one of them, with a README and a demo recording.

| # | Modification | What it does |
|---|---|---|
| 1 | [Time Capsule](<Time Capsule>) | Hold Send to lock a message until a time you choose — frosted over with a live countdown, then the frost melts away. |
| 2 | [Important Posts Notifications](<Important Posts Notifications>) | Notifications for posts that matter — by keyword or post type. Everything else stays muted. |
| 3 | [Multi-Message Reply](<Multi-Message Reply>) | Select 2–5 messages and reply to them all at once, as a swipeable deck of quotes. |
| 4 | [Quick Sticker](<Quick Sticker>) | Hold the sticker icon, slide to a sticker, release — sent without opening the panel. |
| 5 | [Visual Quote](<Visual Quote>) | Select any area of a photo and reply directly to it; tapping the reply opens the photo zoomed to that area. |
| 6 | [Black-Hole Delete](<Black-Hole Delete>) | Clearing a chat's history pulls every message into a black hole in the Dynamic Island. |
| 7 | [Voice Innovation](<Voice Innovation>) | Transcript that syncs with playback, word-level seeking, search, quoting with timestamps, and an AI summary. |

Each folder's README starts with its demo: `1.mp4` … `7.mp4`, numbered in the order above.
